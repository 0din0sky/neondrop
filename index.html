Интеграция бэкенда для NeonDrop

1. Авторизация через Steam (Steam OpenID)

Для входа игроков используется стандартный протокол Steam OpenID. Сервер получает уникальный steamID64, имя и аватар игрока. Пароли не требуются.

2. Приём депозитов CS2 скинами (SkinsBack / Skinify / Waxpeer)

Сервисы SkinsBack API или Waxpeer P2P позволяют принимать скины от пользователей с автоматической оценкой стоимости и моментальным зачислением $ на баланс сайта.

3. Бэкенд и хостинг разработчика

Для разработки подходит недорогой VPS (Hetzner, Timeweb Cloud ~€3-5/мес) на Node.js (Express/Fastify) или Python (FastAPI) с базой данных PostgreSQL для хранения истории дропов и балансов.
